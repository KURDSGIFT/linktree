# LinkHub - لاپەڕەی لینکەکانت

## دەربارە

**LinkHub** پلاتفۆرمێکی خۆڕایییە کە بە بەکارهێنەرەکانی ڕێگەدەدات یەک لاپەڕەی تایبەت بۆ خۆیان دروست بکەن و هەموو سۆشیال مێدیا و لینکی پێویستیان لەسەری دابنێن. یەک لینک — هەمووی لێی دادێت.

## فیچەرەکان

### 🏠 بەشی Home (سەرەکی)
- **پێشاندانی زانیاریی پلاتفۆرمە**: بەکارهێنەرەکان لە یەک نیگایدا بە هەموو فیچەرەکان ئاشنا دەبن
- **دۆگمەی دەستپێکردن**: ڕاستەوخۆ بتبات بۆ تۆمارکردن
- **کاردەکانی فۆری**: ٦ کاردی زانیاریی جوان کە فیچەرەکانی سەرەکی نیشان دەدات

### 🎨 بەشی Template (قاڵب)
- **دیزاینە ٧ جیاواز**:
  - دیزاینی کلاسیک (Classic)
  - دیزاینی گەشاوە (Glow)
  - دیزاینی ڕوون (Light)
  - دیزاینی شووشەیی (Glassmorphism)
  - دیزاینی بوێر (Neo-Brutalism)
  - دیزاینی کەژاوە (Aurora)
  - دیزاینی سادە (Minimalist)
- **مۆدالی فۆرمی**: بەکارهێنەر دەتوانێت زانیاریەکی خۆ داخڵ بکات بۆ هەر دیزاینێک
- **پێشبینین و هەڵبژاردن**: هەر دیزاین دەتوانێت پێشبینی بکرێت یان هەڵبژێردرێت

### 📰 بەشی News (هەواڵ)
- **٦ هەواڵی نوێ**: دەربارەی فیچەرەکانی نوێ و بەرزکردنەکان
- **کاردی هەواڵ**: هەر هەواڵ لە خۆی:
  - ئیکۆنی جیاواز
  - ڕێکەوت
  - توصیف
  - تاگ
  - لینکی "بڕوانە زیاتر"
- **ڕیسپۆنسیڤ**: لەسەر هەموو سایزەکان باش دەردەکەوێت

### ⚙️ بەشی Settings (ڕێکخستنەکان)
- **ڕێکخستنی هەژمار**: ناو، ئیمێیل، ناوی بەکارهێنەر
- **گۆڕینی پاسۆرد**: بە پاسۆردی ئێستا و نوێ
- **تایبەتمەندی**: ڕێکخستنی بینراوی پروفایل
- **ئاگاداریەکان**: ڕێکخستنی جۆرەکانی ئاگاداری
- **ناوچەی خەتەرناک**: سڕینەوەی هەژمار

### ℹ️ بەشی About (دەربارە)
- **٤ تابی جیاواز**:
  - **About**: دەربارەی LinkHub و بیری ئێمە
  - **Contact**: پەیوەندی (ئیمێیل، سۆشیال مێدیا، تێلەفۆن)
  - **Privacy**: پاراستنی زانیاری
  - **Terms**: مەرجەکانی بەکارهێنان
- **بەهاکان**: ٦ بەهای سەرەکی نیشان دەدات

### 📱 ناڤبارێکی ئەستوونی (Vertical Sidebar)
- **ئەستوونی لە سەری چەپ**: ناڤیگەیشن بۆ هەموو بەشەکان
- **لۆگۆ و ناو**: LinkHub بە ئیکۆنی بریقە
- **لینکی چوونەژوورەوە و تۆمارکردن**: لە خواری ناڤبارە
- **موبایل فرێندلی**: دۆگمەی مێنیو بۆ موبایلەکان
- **ئاکتیڤ ناڤیگەیشن**: نیشاندانی پەڕەی ئێستا

## ڕیسپۆنسیڤ ڕێکخستن

### بۆ ڕایانە گەورەکان (Desktop)
- ناڤبارێک بە ٢٥٠px پانی
- کۆنتێنتی سەرەکی بە مارجین لە سەری چەپ
- دۆگمەی مێنیو نیشتمان

### بۆ ڕایانە مامناوەند (Tablet)
- ناڤبارێک بە ٢٠٠px پانی
- کۆنتێنتی سەرەکی بە مارجین لە سەری چەپ
- دۆگمەی مێنیو نیشتمان

### بۆ موبایلەکان (Mobile)
- ناڤبارێک نهێنی (slide-out)
- دۆگمەی مێنیو ڕوونی
- کۆنتێنتی تێدا بە پانی تێدا
- فۆنتی کەمتر بۆ جێگیر بوون

## فایلەکانی پڕۆژە

```
LinkHub-Final/
├── index.html           # بەشی سەرەکی
├── template.html        # بەشی قاڵبەکان
├── news.html            # بەشی هەواڵ
├── settings.html        # بەشی ڕێکخستنەکان
├── about.html           # بەشی دەربارە
├── auth.html            # پەڕەی چوونەژوورەوە و تۆمارکردن
├── dashboard.html       # داشبۆردی بەکارهێنەر
├── profile.html         # پروفایلی بەکارهێنەر
├── contact.html         # پەڕەی پەیوەندی
├── privacy.html         # پاراستنی زانیاری
├── terms.html           # مەرجەکان
├── css/
│   └── main.css         # ستایلی سەرەکی
├── js/
│   ├── config.js        # کۆنفیگی Firebase
│   └── layout.js        # جاڤاسکریپتی لاپەڕە
└── README.md            # ئەم فایلە
```

## بەکارهێنانی پڕۆژە

### بۆ کۆمپیوتەر
1. فایلەکان دا بکە
2. `index.html` بکەرەوە
3. ناڤیگەیشن بەکاربهێنە بۆ گەڕان

### بۆ موبایل
1. لاپەڕە بکەرەوە
2. دۆگمەی مێنیو کلیک بکە
3. ناڤیگەیشن بکەرەوە

## تێکنۆلۆژیا

- **HTML5**: ناوەڕۆکی لاپەڕە
- **CSS3**: ستایل و ڕیسپۆنسیڤ ڕێکخستن
- **JavaScript**: فانکشنالیتی ئینتەراکتیڤ
- **Firebase**: سیستەمی چوونەژوورەوە
- **Font Awesome**: ئیکۆنەکان
